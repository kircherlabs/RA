PORTABILITY
The final ZIP is extracted into a separate directory for launch checks.
Only local HTML, CSS, JavaScript, documentation and rulebook JPG files are
packaged. There are no package installations, CDNs, fetch calls, server
dependencies or runtime APIs. The optional tests require Node only when
run by a developer; the game itself does not.

Direct-file execution has been verified in Edge and Chrome on Windows.
Other modern browsers are expected to support the same standard APIs but
were not tested here. Automatic storage can depend on browser settings;
downloaded JSON saves are the portable save mechanism.
